# FreeCodeCamp: Responsive Web Design Certification

This repository contains my daily practices, exercises, and mini-projects developed while completing the Responsive Web Design certification from freeCodeCamp.

## 🎯 Goal
The purpose of this repository is to track my learning progress in modern HTML5, CSS3, accessibility (WCAG), and responsive layouts, combining them with my experience in conversion rate optimization (CRO) and user experience (UX).

## 📂 Project Structure
*   **01-lasagna-recipe**: Basic HTML structure, semantic elements, and semantic nesting. _(Skills: Semantic HTML5, Data Structuring, Content Hierarchy)_
*   **02-pet-adoption-debug**: Identifying and fixing broken tags, nesting errors, and layout bugs. _(Skills: Code Debugging, Problem Solving, HTML Standards)_
*   **03-travel-agency**: High-conversion landing page with optimized SEO tags and metadata. _(Skills: SEO Optimization, UX/CRO, Responsive Design)_
*   **04-audio-video-player**: Custom audio and video player layout with advanced attributes. _(Skills: Multimedia Elements, Code Standards, HTML5 Layouts)_
*   **05-costa-rica-travel-guide**: Semantic multi-video dashboard bypassing privacy-blocking environments via secure iframe curation. _(Skills: Third-Party Embeds, Iframe Accessibility, Content Hierarchies)_
*   **06-build-an-event-hub**: Semantic event directory dividing future and past concerts with precise time validation and accessible imagery. _(Skills: HTML5 Semantics, Time Element (ISO 8601), Web Accessibility (ALT text), Layout Architecture)_

## 🛠️ Tech Stack
* **HTML5**: Semantic markup and media nesting (`<audio>`, `<video>`, `<figure>`, `<iframe>`).
* **CSS3**: Responsive layouts and multi-screen optimization.
* **Accessibility**: WCAG standards for inclusive user experiences (Descriptive frames).
* **UX/CRO**: Minimalist code structures focused on reducing user friction.
